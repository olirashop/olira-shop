⚙️ قواعد التطبيق

• العروض التلقائية (خصم تلقائي، كمية، باك، اشتري واحصل): يُطبَّق الأفضل للزبونة فقط — لا تُجمع مع بعضها.
• كود التخفيض يُطبَّق فوق العرض التلقائي (إن كان الخيار أعلاه مفعلاً) وإلا تحصل الزبونة على الأفضل منهما.
• "تخفيض الكمية" القديم (من إعدادات المتجر) يبقى يعمل كعرض تلقائي عام.
• التوصيل المجاني من مبلغ عام يُحدَّد أيضاً في "إعدادات المتجر".
• تاريخ النهاية يشمل اليوم كاملاً؛ بعده يتوقف العرض تلقائياً بدون أي تعديل.

النسخ والنشر

نشر التعديلات للزبونات، ونسخة احتياطية

🌍 نشر التعديلات على الموقع

المنتجات والإعدادات تُحفظ في متصفحك أنتِ فقط. الزبونات لا يرونها إلا بعد نشرها بهذه الطريقة.
الخطوات:
1. اضغطي تحميل store-data.js بالأسفل
2. ارفعي الملف على الاستضافة بجانب index.html و admin.html (في نفس المجلد، وعوضي القديم)
3. حدّثي صفحة الموقع — ستظهر المنتجات والأثمنة ورقم الواتساب الجدد عند الجميع
4. كلما عدّلتِ شيئاً، أعيدي الخطوات

🔗 رابط Web App

خطوات الإعداد:
1. افتحي sheets.google.com وأنشئي Sheet جديد
2. من القائمة: Extensions → Apps Script
3. الصقي كود google-apps-script.js واحفظي
4. اضغطي Deploy → New deployment → Web app
5. اختاري "Anyone" في خانة "Who has access"
6. انسخي الرابط والصقيه هنا
